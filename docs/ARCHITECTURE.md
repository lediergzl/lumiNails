# Arquitectura

Dos apps Capacitor independientes: Cliente y Manicurista.

Supabase/PostgreSQL será la fuente de verdad para datos transaccionales. SQLite será la base local para el funcionamiento offline. Las imágenes se procesarán en el dispositivo y se almacenarán fuera de Supabase.

La licencia del proveedor será server-authoritative. El período de prueba inicial es de 14 días; después se requiere licencia activa.
